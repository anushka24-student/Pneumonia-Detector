# Pneumonia Detection Using Deep Learning

## About the Project
This project uses **VGG16 Transfer Learning** to classify chest X-ray images into two categories: **Normal** and **Pneumonia**. It uses Python and TensorFlow/Keras to train and evaluate the deep learning model.

## Features
- Chest X-ray image classification
- Image preprocessing and data augmentation
- Model evaluation using performance metrics
- Grad-CAM visualizations to help interpret predictions

## Technologies Used
- Python
- TensorFlow / Keras
- VGG16
- NumPy, Matplotlib, Scikit-learn

## How to Run
1. Clone this repository.
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Open `pneumonia_detector_polished.ipynb` in Google Colab or Jupyter Notebook.
4. Configure the dataset path and run the notebook cells.

## Disclaimer
This project is for **educational purposes only** and is not intended for medical diagnosis or clinical decision-making.
